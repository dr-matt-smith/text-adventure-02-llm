# version 3

display arrows for default sequence of nodes


## Story properties - default sequence connections

add a new property:
- Show default sequence graph connections (checkbox)

- when selected, offer radio buttons for: "Default arrow line stype:"
    - dashed (default)
    - solid

- when selected, offer radio buttons for: "Default arrow line color:"
    -  color picker (default to yellow)

- when selected, offer radio buttons for: "Default arrow alpha:"
    - as a slider (default to 75%)

## Story properties - default sequence number

WHEN "Show default sequence nav buttons (checkbox)" is selected, 

THEN show a new property:
- Show default sequence slide number (checkbox)

when CHECKED add "<s>/<t>" in between the navigation arrows 
(<s> current slide number in sequence, <t> total number of slides)
